## 🔧 Troubleshooting

If you encounter issues, try these steps:

- **Trainer doesn't load:** Make sure you're opening the index.html file in a modern browser, not an older one like Internet Explorer.
- **Movement feels laggy:** Close other browser tabs or programs to free up memory.
- **Can't see the path:** Adjust your browser zoom level (Ctrl + or Ctrl -) to fit the whole game window.
- **Buttons don't respond:** Click the game window first to give it focus, then try again.
